앱 열기

공개 체험개발 중인 학급 안내 앱

공지를 올리면 누가 확인했는지 바로 보여요.

공지·준비물·일정을 한곳에 올리는 학급 안내 앱이에요. 학생은 오늘 할 일을 먼저 보고, 선생님은 아직 확인하지 않은 학생을 바로 볼 수 있어요.

우리반 허브 열기 사용 예시 보기

개발 중인 앱을 열어 보세요. 교사 기능은 운영자 승인 후 사용할 수 있어요. 실제 학생 개인정보 대신 예시 정보로 체험해 주세요. 이용 안내

  • 앱 설치 없이 사용
  • 지원 기기에서 알림 허용 후 사용
  • 학생은 중학교 3학년 이상

단체 대화방 공지에서 생기는 걱정

  • 대화가 많으면 공지를 찾기 어려워요공지를 놓치지 않아요

    학생 화면 맨 위에 아직 보지 않은 공지가 나와요.

  • 공지 내용이 바뀌었어요바뀐 내용을 다시 확인받아요

    공지를 고치면 이미 확인한 학생도 바뀐 내용을 다시 확인해요.

  • 연락처가 걱정돼요전화번호와 채팅이 없어요

    전화번호를 받지 않아요. 궁금한 점은 '도움 요청' 버튼으로 선생님께 보내요.

시작 방법

처음 쓰는 날은 이 순서로 하면 돼요.

  1. 반 만들기

    학교와 학년·반을 고르면 초대 코드가 생겨요.

  2. QR 코드 보여 주기

    학생은 휴대폰으로 QR 코드를 찍거나 초대 코드를 입력해 참여를 요청해요.

  3. 학생 승인하기

    학생 번호와 이름을 정하고 '모두 승인' 버튼으로 한꺼번에 승인해요.

  4. 첫 공지 쓰기

    공지를 올리면 누가 확인했는지 바로 보여요.

사용 예시

공지를 올리고 학생이 확인하기까지, 하루를 예로 보여 드려요.

체육대회 안내 공지를 올린 날, 선생님과 학생이 하는 일을 시간 순서로 보여 드려요.

1아침

공지를 올리면 학생 화면 맨 위에 나와요.

  1. 선생님

    체육대회 공지를 올려요. 반 전체나 원하는 학생에게만 보낼 수 있어요.

  2. 학생

    홈 맨 위에서 공지를 읽고 '공지 확인하기'를 눌러요.

  3. 알림

    지원 기기에서 홈 화면에 추가하고 알림을 허용하면 알림을 받아요. 수업 시간과 밤에는 알림을 바로 보내지 않고, 나중에 모아서 보내요.

2점심 · 오후

아직 확인하지 않은 학생에게만 다시 알려요.

  1. 선생님

    확인한 학생과 아직 확인하지 않은 학생이 나뉘어 보여요.

  2. 공지 수정

    오후에 공지를 고치면 이미 확인한 학생도 다시 확인해요. 몇 명이 새 내용을 봤는지도 보여요.

  3. 다시 알리기

    아직 확인하지 않은 학생에게만 앱 안에서 다시 알려요.

3방과 후

준비가 어려운 학생은 버튼으로 선생님께 알려요.

  1. 학생

    '준비하기 어려워요'를 누르고 "집에 물감이 없어요"처럼 짧게 적어요.

  2. 선생님

    한 줄로 답하고 '처리 완료'를 누르면 학생 화면에 보여요.

  3. 선생님

    '학생별 미해결 모아보기'에서 아직 확인하지 않은 학생을 한 번에 봐요.

화면 속 이름과 날짜는 예시예요.

개인정보와 안전

꼭 필요한 정보만 받고, 선생님이 승인한 학생만 들어와요.

  • 선생님이 승인해야 들어와요

    코드를 알아도 승인 전에는 반 자료를 볼 수 없어요.

  • 전화번호와 채팅이 없어요

    이메일로 가입하고, 승인 화면에서도 이메일 일부는 가려져요. 학생끼리 대화하는 기능은 없어요.

  • 만 14세 이상만 참여해요

    공개 체험은 만 14세 이상, 학생은 중학교 3학년 이상을 대상으로 해요.

  • 개인정보 안내도 개발 중이에요

    앱의 개인정보 안내는 개발본이에요. 실제 학급 운영에 앞서 확정·게시할 예정이며, 지금은 예시 정보로 체험해 주세요.

  • 반 관리는 선생님이 해요

    선생님이 학생을 반에서 뺄 수 있고, 반을 관리한 기록도 남아요.

  • 계정은 직접 삭제할 수 있어요

    설정에서 계정 삭제를 요청할 수 있어요. 실제 학생의 자료를 보관하는 용도로는 아직 사용하지 마세요.

미리 알려 드려요

  • 개발자가 직접 서버를 운영해요. 점검·재시작 중에는 잠시 접속이 안 될 수 있어요.
  • 학부모 화면은 아직 없어요.

실제 학급 운영을 시작하기 전의 체험판이에요. 학생의 실제 이름·연락처·상담 내용 등 개인정보 대신 예시 정보를 사용해 주세요.

시작하기

앱을 설치해야 하나요?

아니요. 인터넷 창(크롬·사파리)으로 열면 돼요. 알림을 받으려면 지원 기기에서 홈 화면에 추가하고 알림을 허용해 주세요.

어떻게 시작하나요?

'우리반 허브 열기'를 누르면 최신 앱 주소로 이동해요. 회원가입·이메일 인증 후 로그인해 주세요. 교사 기능은 별도 운영자 승인이 필요하므로 가입 후 메일로 문의해 주세요. 실제 학생 개인정보 대신 예시 정보로 체험해 주세요.

초등학생이나 중학교 1·2학년도 쓸 수 있나요?

공개 체험도 만 14세 이상, 학생은 중학교 3학년 이상을 대상으로 해요.

초대 코드가 다른 사람에게 알려지면요?

괜찮아요. 선생님이 승인해야 들어올 수 있어요. 코드는 기한이 있고, 새로 만들 수도 있어요.

앱이 열리지 않으면 어떻게 하나요?

점검·재시작 중에는 잠시 접속이 끊길 수 있어요. 예전에 저장한 앱 주소 대신 이 소개 페이지의 앱 열기 버튼으로 다시 시도해 주세요. 새 주소가 반영되기까지 몇 분 걸릴 수 있어요. 계속 열리지 않으면 메일로 알려 주세요.

쓰는 방법

단체 대화방과 무엇이 다른가요?

대화방에서는 누가 봤는지, 고친 내용을 다시 봤는지 알기 어려워요. 우리반 허브는 확인한 학생과 확인하지 않은 학생을 보여 주고, 고치면 다시 확인받아요.

일부 학생에게만 보낼 수 있나요?

네. 반 전체나 원하는 학생에게만 보낼 수 있어요.

지난 공지를 다시 쓸 수 있나요?

네. 예전 공지·숙제를 불러와 고쳐서 올리면 돼요. 마감일·중요 표시·받을 학생은 새로 골라요.

일정이 바뀌면 공지를 하나하나 고쳐야 하나요?

아니요. 일정을 고치면 연결되어 있던 공지·준비물을 한 화면에 모아 줘요. '변경'이나 '유지'만 고르면 한꺼번에 반영돼요.

확인하지 않은 학생에게 다시 알릴 수 있나요?

네. 아직 확인하지 않은 학생에게만 앱 안에서 다시 알려요. 학생마다 무엇을 아직 확인하지 않았는지는 '학생별 미해결 모아보기'에서 한 번에 볼 수 있어요.

도움 요청은 채팅인가요?

아니요. '질문 있어요'나 '준비하기 어려워요'를 누르고 짧게 적어 보내면 선생님만 봐요. 선생님은 한 줄로 답해요.

밤에도 알림이 오나요?
